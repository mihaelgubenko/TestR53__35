# Урок 6. Обработка исключений в Python

## Главная идея

`try / except` - это механизм обработки ошибок.

Простыми словами:

```text
try = попробуй выполнить код
except = если произошла ошибка, обработай ее
```

Это не песочница антивируса.  
Песочница изолирует опасный файл от системы.  
`try / except` не изолирует код, а ловит ошибку внутри программы и дает запасной сценарий.

Главный смысл:

```text
Программа не просто падает, а понятно сообщает, что пошло не так.
```

## Основные понятия

Ошибка - ситуация, когда программа не может продолжать работу.

Пример:

```python
10 / 0
```

Исключение - конкретный тип ошибки.

Пример:

```text
ZeroDivisionError
```

Traceback - отчет Python о том, где произошла ошибка.

Он показывает:

```text
файл
строку
тип ошибки
причину ошибки
```

## Пример: деление на ноль

Код:

```python
result = 10 / 0
```

Ошибка:

```text
ZeroDivisionError: division by zero
```

Смысл:

```text
Python не может делить на ноль.
```

Обработка:

```python
try:
    result = 10 / 0
except ZeroDivisionError:
    print("Ошибка: нельзя делить на ноль")
```

## Почему строки превращаются в числа

В реальных программах данные часто приходят строками:

```text
input()
файлы
CSV
JSON
API
формы на сайте
```

Например:

```python
age_from_input = "25"
```

Это строка, а не число.

Чтобы сделать из нее число:

```python
age_as_number = int(age_from_input)
```

Теперь можно считать:

```python
print(age_as_number + 5)
```

Для дробных чисел:

```python
price = float("19.99")
```

Если строка не похожа на число:

```python
float("hello")
```

Будет ошибка:

```text
ValueError
```

## Пример: проверка преобразования

```python
try:
    number = float("hello")
    print(number)
except ValueError:
    print("Ошибка: строку нельзя превратить в число")
```

Смысл:

```text
Попробуй сделать число.
Если не получилось, покажи понятное сообщение.
```

## Уровни кода в калькуляторе

В уроке код разделен на уровни.

Низкий уровень только считает:

```python
def calculate(a: float, b: float, op: str):
    if op == "+":
        return a + b
    elif op == "-":
        return a - b
    elif op == "*":
        return a * b
    elif op == "/":
        return a / b
    else:
        raise ValueError("Unknown operation")
```

Возможные ошибки:

```text
ZeroDivisionError - деление на ноль
ValueError - неизвестная операция
```

Средний уровень превращает строки в числа:

```python
def parse_and_calculate(a_str: str, b_str: str, op: str):
    a = float(a_str)
    b = float(b_str)
    return calculate(a, b, op)
```

Возможная ошибка:

```text
ValueError - строка не является числом
```

Высокий уровень ловит ошибки:

```python
def safe_calculator(a_str: str, b_str: str, op: str):
    try:
        result = parse_and_calculate(a_str, b_str, op)
        print("Result:", result)
    except ZeroDivisionError:
        print("Ошибка: нельзя делить на ноль")
    except ValueError as error:
        print("Ошибка в данных:", error)
```

Смысл:

```text
Низкий уровень делает работу.
Средний уровень готовит данные.
Высокий уровень общается с человеком и обрабатывает ошибки.
```

## Пример с файлом

Файл может отсутствовать. Поэтому чтение файла - место возможного сбоя.

```python
try:
    with open("user.json", "r", encoding="utf-8") as nfile:
        print(nfile.read())
except FileNotFoundError:
    print("Ошибка: файл user.json не найден")
```

## else и finally

`else` выполняется только если ошибки не было.

`finally` выполняется всегда.

Пример без ошибки:

```python
try:
    value = int("123")
except ValueError:
    print("Это не число")
else:
    print("Преобразование прошло успешно:", value)
finally:
    print("Этот блок выполняется всегда")
```

Пример с ошибкой:

```python
try:
    value = int("gffgfg")
except ValueError:
    print("Это не число")
else:
    print("Преобразование прошло успешно:", value)
finally:
    print("Этот блок выполняется всегда")
```

Смысл:

```text
try - пробуем
except - ловим ошибку
else - если ошибки не было
finally - выполняем всегда
```

## raise

`raise` позволяет создать ошибку вручную.

Пример:

```python
raise ValueError("Unknown operation")
```

Смысл:

```text
Если операция неизвестна, программа сама сообщает об ошибке.
```

## Вопросы и ответы

Вопрос: Это как трекер ошибок?  
Ответ: Traceback - да, он показывает путь к ошибке. `try / except` - это обработка ошибки.

Вопрос: Это механизм обработки отказа?  
Ответ: Да, по смыслу верно. Профессионально это называется обработка исключений.

Вопрос: Это как песочница антивируса?  
Ответ: Нет. Песочница изолирует опасный код. `try / except` не изолирует, а ловит ошибку и выполняет запасной сценарий.

Вопрос: Откуда знать, какое исключение писать?  
Ответ: Python сам показывает тип ошибки в traceback.

Вопрос: Почему Python понял строку как число?  
Ответ: Python не сам понял. Мы явно попросили преобразовать строку через `int()` или `float()`.

Вопрос: Почему не писать сразу числа?  
Ответ: Потому что реальные данные часто приходят строками из `input()`, файлов, CSV, JSON, API и форм на сайте.

Вопрос: ООП заменяет `try / except`?  
Ответ: Нет. ООП организует код, а `try / except` обрабатывает сбой.
